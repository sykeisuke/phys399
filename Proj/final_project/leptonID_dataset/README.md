**This dataset is not stored in the repository.** Due to file size, it is hosted on Google Drive.

## ダウンロード / Download

Google Driveのリンク / Google Drive link:
https://drive.google.com/drive/folders/1qGtNOhUDPIoF4qhtbLfTfGG1aoA6aOJf?usp=drive_link

## 使用方法 / Usage

1. 上記のGoogle Driveリンクからダウンロードしてください。
   Download from the Google Drive link above.

2. `train.csv` と `test.csv` をこのディレクトリに置いてください。
   Place `train.csv` and `test.csv` directly in this directory.

3. その後、既存のノートブックとスクリプトは通常通り動作します。
   After that, existing notebooks and scripts will work as usual.
